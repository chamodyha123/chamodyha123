**Tech Stack:**
`Next.js` `Express.js` `Prisma` `PostgreSQL` `Socket.IO` `REST API`

A full-stack Sri Lankan bus transportation platform designed to connect passengers, bus owners, drivers, conductors and administrators.

**Key Features:**

* 🚌 Bus registration and management
* 📍 Real-time bus tracking
* 🎫 Trip-based seat reservation
* 👥 Passenger, Driver, Conductor, Owner & Admin roles
* 🗺️ Route and trip management
* 🔔 Notifications
* 🚨 SOS and unsafe-area reporting
* 📱 Real-time communication using Socket.IO
* 🔐 Role-based authentication and authorization

`Laravel` `PHP` `PostgreSQL` `Eloquent` `Sanctum` `Flutter` `Dart` `Next.js` `TypeScript`

A multi-vendor wedding marketplace designed to help couples discover, compare, book and manage wedding-related services.

**Key Features:**

* 💒 Wedding service marketplace
* 👰 Multiple service categories
* 🏢 Service provider registration
* 🔎 Provider verification workflow
* 👨‍💼 Customer / Provider / Admin roles
* 🔐 Laravel Sanctum authentication
* 💰 Booking and payment architecture
* 📊 Wedding budget management
* 💌 Digital invitations
* 📱 Flutter mobile application
* 🌐 Next.js web platform
* 🗄️ PostgreSQL database
* ☁️ Cloud-ready architecture

**Provider Workflow:**

```text

       ↓
Select Categories
       ↓
Pending Verification
       ↓
Admin Review
       ↓

       ↓
Public Marketplace
```
